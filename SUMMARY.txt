10 CORE MODULES
════════════════════════════════════════════════════════════════════════════

1. CONFIG          → Central settings: instrument, trading & data periods, features, risk (all via .env)
2. DATA LAYER      → Fetch historical candles & live prices from OpenBB Platform
3. FEATURES        → Transform price → AI-friendly numbers (SMA, RSI, ATR)
4. MODEL/SIGNAL    → AI core: features → BUY/SELL/HOLD + confidence
5. RISK MGMT       → Optional settings: exposure cap, sizing, stop/take.
                     EMPTY MEANS NOT APPLIED; no master switch. Loss limits
                     (MAX_LOSS_PERCENT / MAX_CONSECUTIVE_LOSSES) are collected but
                     NOT applied — they belong to the execution loop.
6. STRATEGY        → ONE state machine (src/strategy) both the backtest and a live
                     run drive; parity is enforced by test
7. EXECUTION       → Place bracketed orders on Alpaca via its API (data comes from
                     OpenBB). Built, and the loop drives it (src/scheduler)
8. STATE TRACKER   → DynamoDB table (positions, P&L, trades)  [not built]
9. SCHEDULER       → Main loop over closed bars (own process)  [built]
10. LOGGING/WEB PORTAL → Structured logs + dashboard (progress, charts, config, alerts)
11. BACKTESTER     → Validate strategy on historical data before live

KEY DESIGN DECISIONS
════════════════════════════════════════════════════════════════════════════

✓ Polling (4-hour intervals) vs Websocket
  → Polling: simpler, no persistent connection, perfect for non-day-trading

✓ DynamoDB (managed) vs PostgreSQL
  → DynamoDB: managed, durable, scales without ops; supports PITR and export to S3 for archival

✓ OpenBB Platform (data) + Alpaca (execution)
  → OpenBB aggregates market data providers behind one SDK (free providers, no broker auth);
    Alpaca kept only for order placement since OpenBB cannot execute trades

✓ Simple AI (Logistic Regression) vs Neural Nets
  → Simple: fast, debuggable, good edge, upgrade later if needed

✓ Backtest before live (non-negotiable)
  → Validates strategy has edge, catches bugs, de-risks real money

✓ Docker + AWS Lightsail
  → Reproducible, managed, cheap (~$15-20/month), auto-scaling


COMMON PITFALLS TO AVOID
════════════════════════════════════════════════════════════════════════════

❌ Hardcoding credentials anywhere
   → Use .env + AWS Secrets Manager

❌ Skipping backtesting
   → Backtest everything before live (non-negotiable)

❌ Starting with huge positions
   → Start with 1% of capital, prove yourself first

❌ Ignoring comprehensive logging
   → You'll need logs to debug issues months later

❌ Assuming perfect execution
   → Network fails, orders rejected, build retry logic

❌ Skipping paper trading
   → 1-2 weeks on paper catches 80% of bugs before real money
